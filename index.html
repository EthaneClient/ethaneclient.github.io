Install

Four steps.
No installer.

  1. 01

    Fabric Loader

    Install Fabric 0.17.3 or newer for Minecraft 1.21.11.

  2. 02

    Fabric API

    Drop Fabric API into .minecraft/mods.

  3. 03

    Ethane

    Download Ethane.jar and put it next to Fabric API.

  4. 04

    Launch

    Pick the Fabric profile, join a world, hit RShift.
